# AgriCounty-Server-Pack

AgriCounty Server Pack v1.0.0

Initial production release of the custom server-side gameplay mods
used by the AgriCounty Farming Simulator 25 server.

Included Mods
-------------
FS25_AgriCounty.zip
- AgriCounty OS v0.5.1
- Unauthorized crop-damage financial liability
- Unauthorized damage assessed at 2x destroyed crop value

FS25_OneFarmPerPlayer.zip
- One Farm Per Player v0.6.4
- Restricts each player to creating one farm
- Creation entitlement persists after leaving/deleting the original farm

FS25_WorkerCosts.zip
- Realistic Worker Costs - Server Economy v2.2.2.4
- Persistent farm-specific employee rosters
- $75/hour base worker rate
- Maximum 10 employees per farm
- Maximum 5 new hires per farm per day

Installation
------------
1. Download AgriCounty-Server-Pack-V1.0.0.zip.
2. Extract the download.
3. Place all three included FS25_*.zip files into your Farming Simulator 25 mods folder.
4. Do NOT extract the individual FS25 mod ZIP files.
5. Start Farming Simulator 25 and enable the required mods.

This package contains only the custom mods maintained for the
AgriCounty server. Other required public/ModHub mods are distributed
separately.
